# Night Rain Taxi 夜雨タクシー

Fly a cab through a city where it never stops raining. Pick up fares, thread the traffic, and in the Getaway shift, shake off the Kuro cab gang.

**Play it here: https://lordkev007.github.io/NightRainTaxi/**

Best in Chrome or Edge on a PC, with an Xbox (or other) controller. Press any button on the controller once to wake it up.

## Download for Steam Deck or Windows

Grab the newest files from the [Releases page](https://github.com/LordKev007/NightRainTaxi/releases):

- **Steam Deck:** `NightRainTaxi-x.y.z.AppImage`. In Desktop Mode, right-click it, Properties, Permissions, tick "Is executable", then right-click again and "Add to Steam".
- **Windows:** `NightRainTaxi-Setup-x.y.z.exe`. Windows may warn that it is from an unknown publisher: choose "More info", then "Run anyway".

Install once. When a new version is posted here, the title screen offers "Update to vX", which downloads in a moment.

## Modes

- **Rival Rush**: 100 seconds on the clock, more for every delivery, while four rival Kuro cabs hunt you. Lead them into walls, bridges and traffic.
- **Meter Madness**: every passenger is on a clock. Miss three fares and the shift is over.
- **Joy Ride**: no clock, no gang. Just fly.

## High scores

Rival Rush, Rival Rush with clocks off, and Meter Madness each keep a top ten. Make the list and you enter three initials, arcade style.

## Controls

| | Controller | Keyboard |
|---|---|---|
| Steer | Left stick | A / D |
| Climb, dive | Left stick up / down | Space / C, or ↑ / ↓ (the stick and arrows can be flipped in Options → Controller) |
| Throttle, brake | RT / LT | W / S |
| Boost | A | Shift |
| Slide sideways | LB / RB | Q / E |
| Look around | Right stick | |
| Horn | X | H |
| Pause | Menu | Esc |
| Mute, fullscreen | | M, F |

Damage level, clocks, sound and picture settings are under Options.

## How it's made

The whole game is the single `index.html` file: code, graphics, neon signs and sound are all generated in the browser, with no images or audio files.
