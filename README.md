# Night Rain Taxi 夜雨タクシー

Fly a cab through a city where it never stops raining. Pick up fares, thread the traffic, and in the Getaway shift, shake off the Kuro cab gang.

**Play it here: https://lordkev007.github.io/NightRainTaxi/**

Best in Chrome or Edge on a PC, with an Xbox (or other) controller. Press any button on the controller once to wake it up.

## Modes

- **Start a shift**: every passenger is on a clock. Miss three fares and the shift is over.
- **Getaway shift**: 100 seconds on the clock, more for every delivery, while four rival cabs hunt you. Lead them into walls, bridges and traffic.
- **Just cruise**: no clock, no gang.

## Controls

| | Controller | Keyboard |
|---|---|---|
| Steer | Left stick | A / D |
| Climb, dive | Left stick up / down | Space / C, or ↑ / ↓ |
| Throttle, brake | RT / LT | W / S |
| Boost | A | Shift |
| Slide sideways | LB / RB | Q / E |
| Look around | Right stick | |
| Horn | X | H |
| Pause | Menu | Esc |
| Mute, fullscreen | | M, F |

Damage level, clocks, sound and picture settings are under Options.

## How it's made

The whole game is the single `index.html` file: code, graphics, neon signs and sound are all generated in the browser, with no images or audio files.
